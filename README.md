# 테마 스캐너

3개월 전고점을 돌파한 강양봉을 테마별로 모아 보여주는 사이트예요. 매일 장 마감 후 자동으로 갱신돼요.

- 포착 조건: 양봉 + 종가 +15% 이상 + 거래대금 500억 이상 + 종가가 직전 3개월 장중 고가 최고치 돌파
- 바닥대비: 직전 3개월 최저 저가 대비 종가 상승률
- 테마: 네이버 금융 테마 (한 종목이 여러 테마에 속할 수 있어요)
- 순위 TOP 10: 최근 7/30/90일 동안 같은 테마에서 포착된 종목 수 (같으면 거래대금 합계)
- 백데이터: 2026-06-01부터 (`TH_SINCE` 환경변수로 변경)
- 텔레그램 알림 없음

실행: Actions → theme_scan → Run workflow (force에 1 입력하면 장 마감 후 아무 때나 실행)
